# Entities & Components

Pure ECS. Entity = just ID (uint). Component = pure data (struct).

## Entity Lifecycle

- `ECSOperator.CreateEntity()` → return `Entity` struct. Reuse old ID if destroyed.
- `ECSOperator.DestroyEntity(Entity)` → clear components, recycle ID.
- Queued in `ThreadSafeECSOperator` for safe destruction.

## Built-in Components

| Component | Purpose | Unity Equivalent |
|-----------|---------|-------------------|
| `CoordComponent` | Pos / Scale / PrevPos / ModelMatrix (for instancing) | Transform |
| `CubeRendererComponent` | Flag for 3D render | MeshRenderer |
| `EnabledComponent` | Active flag | GameObject.activeSelf |
| `DestroyedComponent` | Mark for cleanup | Object.Destroy |
| `PhysicsBodyComponent` | Dynamic mass body (Jolt) + bury/quality/LOD | Rigidbody |
| `StaticPhysicsBodyComponent` | Static collider (Jolt) + LOD | MeshCollider / BoxCollider |
| `InitialVelocityComponent` | Set initial linear+angular velocity (Jolt) | Rigidbody.velocity |
| `JumpComponent` | Configurable jump impulses (cooldown, min/max random) | Jump force system |
| `PlayerControllableComponent` | Input speed + IsGodMode flag | PlayerController Script |
| `GameCameraComponent` | Cam3D, Orbit mode (Yaw/Pitch/Distance), DrawDistance, Offset | Camera + Follow Script |
| `SceneMemberComponent` | Track scene ownership | SceneManager bounds |
| `BulletComponent` | Bullet lifetime tracking | Projectile timer |
| `BulletRendererComponent` | Marker for bullet rendering (yellow color) | Bullet mesh flag |
| `BulletSpawnerComponent` | Spawn cooldown, bullet speed/scale/mass | Weapon config |
| `CubeSpawnerComponent` | Cube spawn cooldown config | Factory config |
| `SurfaceBlockComponent` | Marker for terrain surface blocks | Voxel surface flag |
| `BlockTypeComponent` | Block type enum (Grass, Dirt, Stone, etc.) | Voxel type data |

## New Physics-related Components (recent additions)

- BulletComponent: Lightweight descriptor for a bullet entity's lifetime. Tracks current lifetime and maximum lifetime.
- BulletRendererComponent: Marker component to indicate an entity should be rendered as a bullet (no data).
- BulletSpawnerComponent: Controls bullet spawning cadence and parameters such as speed, scale and mass.
- InitialVelocityComponent: Sets the initial linear and angular velocity when an entity is spawned with a physics body.
- JumpComponent: Configures per-entity jump impulse behavior (cooldown, min/max jump forces).
- CubeSpawnerComponent: Controls cube spawning cooldown via ComponentArray (not used in current main scene).
- SurfaceBlockComponent: Marker for terrain surface blocks generated by WorldGeneratorSystem.
- BlockTypeComponent: Stores the block type enum for terrain blocks.
- ComponentArray: Core infrastructure used by ECS to store and iterate components; acts as the dense storage for components of a given type.

```csharp
public struct BulletComponent
{
    public float Lifetime;
    public float MaxLifetime;

    public BulletComponent(float maxLifetime = 5f)
    {
        Lifetime = 0f;
        MaxLifetime = maxLifetime;
    }
}
```

- BulletSpawnerComponent
```csharp
public struct BulletSpawnerComponent
{
    public float Cooldown;
    public float CurrentCooldown;
    public float BulletSpeed;
    public Vector3 BulletScale;
    public float BulletMass;

    public BulletSpawnerComponent()
    {
        Cooldown = 0.1f;
        CurrentCooldown = 0f;
```

- ComponentArray<T> (core storage)

```csharp
    public int Count = 0;
    private readonly Dictionary<Entity, int> _denseIndex = new();
    public void AddComponent(Entity entity, T component) { /*...*/ }
    public void RemoveComponent(Entity entity) { /*...*/ }
    public T GetComponent(Entity entity) => Components[entity];

```

> Nota: estos componentes se usan en conjunto con los sistemas de Physics y Render para gestionar entidades con comportamiento de proyectil, disparo y movimiento inicial.

### Quick Reference

```csharp
// Dynamic body with LOD
var dynamic = new PhysicsBodyComponent
{
    Mass = 1.0f,
    UseLod = true,
    LodDisableDistance = 100f
};

// Static collider
var static = new StaticPhysicsBodyComponent
{
    UseLod = true,
    LodDisableDistance = 200f
};

// Initial velocity
var vel = new InitialVelocityComponent
{
    LinearVelocity = new Vector3(10, 5, 0)
};

// Jump behavior
var jump = new JumpComponent
{
    Cooldown = 0.5f,
    MinJumpForce = new Vector3(-1, 8, -1),
    MaxJumpForce = new Vector3(1, 12, 1)
};
```
